# Future Windows app API
Base path: `/api`. Authenticate with `Authorization: Bearer <Supabase access token>` over HTTPS. `POST /license` body `{ "licenseId": "uuid" }` returns `{ "valid": boolean, "status": "active|revoked", "deviceLimit": number }`. `POST /activate` body `{ "licenseId": "uuid", "deviceId": "opaque identifier" }` returns `{ "activated": boolean }` or HTTP 409. The server must never accept executable optimization commands from the web. Do not transmit PC telemetry without explicit opt-in. Endpoints for software versions, update signing, opt-in reports, refresh tokens and offline activation are not implemented.
